# Security policy

Please do not report suspected security or privacy vulnerabilities in public issues or pull requests.

Email [ejameson2010@gmail.com](mailto:ejameson2010@gmail.com) with a description, affected version or commit, reproduction steps, and potential impact. Do not include real users' personal information or credentials. If sensitive material is necessary, request a secure way to share it.

The maintainer will review reports as capacity permits and coordinate remediation and disclosure with the reporter. Only the current default branch is supported; there is no guaranteed response time.
